## 🚀 Getting Started

### 1. View Locally
Simply clone the repository and open `index.html` in your web browser:

```bash
# Clone the repository
git clone https://github.com/GOKULKRISHNAN2044/portfolio.git

# Navigate into the folder
cd portfolio

# Open in browser (Windows)
start index.html
```

Or serve with Python's built-in HTTP server:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Deploy to GitHub Pages (Free Hosting)

To make your portfolio accessible live on the web:
1. Go to your repository on GitHub: **[GOKULKRISHNAN2044/portfolio](https://github.com/GOKULKRISHNAN2044/portfolio)**
2. Click **Settings** (tab on the top right).
3. On the left sidebar, click **Pages**.
4. Under **Build and deployment > Branch**:
   - Source: Select **Deploy from a branch**
   - Branch: Select **`main`** / Folder: **`/ (root)`**
   - Click **Save**.
5. In 1–2 minutes, your website will be live at:
   👉 **`https://gokulkrishnan2044.github.io/portfolio/`**
